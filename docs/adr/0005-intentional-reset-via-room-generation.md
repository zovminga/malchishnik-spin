# Intentional reset via Room Generation

Score Clear and Game Restart must stick for every device, but empty-phone joins must still not wipe a live party. We keep Firebase and Night Progress (ADR-0001), and add Room Generation: only those intentional actions bump it, and a higher generation always wins even when scores/log/Players shrink. The old local «сброс кэша» control is removed so party-wide clears go only through Score Clear / Game Restart. Ordinary single-Player removal stays under Night Progress (ADR-0004) and does not bump Room Generation. Rejected: a new server/CRDT stack, last-write-wins for all writes, and a host-only reset role.
