# МАЛЬЧИШНИК — рулетка

Казино-рулетка: крутишь колесо и решаешь, куда идти дальше.

**Места:** казино · бар · стрипуха · KC Grad · компы · тир · клуб

## Простой способ (один HTML)

Открой файл [`malchishnik.html`](./malchishnik.html) двойным кликом в браузере — ничего устанавливать не нужно.

Или локальный сервер:

```bash
python3 -m http.server 8765
```

Открой http://127.0.0.1:8765/malchishnik.html

## React-версия (Vite)

```bash
npm install
npm run start
```

http://127.0.0.1:43177
