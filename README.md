# МАЛЬЧИШНИК — рулетка

Казино-рулетка: крутишь колесо и решаешь, куда идти дальше.

**Сайт:** https://zovminga.github.io/malchishnik-spin/

**Места:** казино · бар · стрипуха · KC Grad · компы · тир · 33 · гиннес · покемон

После места у части опций крутится **однорукий бандит** с заданием. Есть игроки, очки и лог ночи.

## Простой способ (один HTML)

Открой [`index.html`](./index.html) (или [`malchishnik.html`](./malchishnik.html)) двойным кликом в браузере.

Или локальный сервер:

```bash
python3 -m http.server 8765
```

Открой http://127.0.0.1:8765/malchishnik.html

## React-версия (Vite)

```bash
npm install
npm run start
```
