# НА ЗЕРО — рулетка мальчишника

Мини-лендинг с казино-рулеткой: крутишь колесо и решаешь, куда идти дальше.

**Места на колесе:** казино · бар · стрипуха · KC Grad · компы

## Запуск

```bash
npm install
npm run dev
```

Открой [http://127.0.0.1:43177](http://127.0.0.1:43177).

## Скрипты

| Команда        | Что делает              |
| -------------- | ----------------------- |
| `npm run dev`  | Dev-сервер на порту 43177 |
| `npm run build`| Production-сборка       |
| `npm run preview` | Превью сборки        |

Стек: Vite, React, TypeScript, Tailwind CSS v4.
